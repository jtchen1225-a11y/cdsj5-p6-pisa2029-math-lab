# 聖若瑟教區中學第五校 · 小學六年級數學思維課（30週）
## 面向 PISA 2029 全球素養培育校本教材、互動實驗室與課堂工作紙全集

本專案為聖若瑟教區中學第五校小六級（面向 PISA 2029 參測核心梯隊）量身研發之數學思維課全套落地教學成果，全套包含：
1. **30 週線上互動實驗室（動態沙盒）**：零安裝、免登入、純前端，支援 iPad、筆記型電腦與課堂大螢幕觸控投影。
2. **30 週課堂探究單工作紙全集（每課一張 A4 紙，共 2 版）**：包含情境審查、動態實驗數據記錄表、CER 學術論證實踐、PISA 2029 基礎精準練、拓展突破題及評估量表。

### 🎮 線上互動實驗室操作特色 (app.js + index.html)

每個週次均對應專屬獨立實驗沙盒，支援多種即時互動操作：
- **滑桿調節 (Sliders)**：動態調節自變數（如配比份數、長寬高、水深降雨、折扣率、樣本數、旋轉角度）。
- **實體平移與裁切 (Dragging & Translation)**：緞帶度量除法、積木三視圖堆疊、折扣運算順序換位。
- **角度旋轉 (Rotation)**：正方體 11 種展開圖立體摺疊（0°～90°）、車輪旋轉震盪頻率。
- **元素添加與刪除 (Add/Remove)**：天平左右盤砝碼增減、智慧停車場車型調配、極端值薪資注入。
- **CER 論證真相揭示**：一鍵展開/收起學術級主張（Claim）、證據（Evidence）、推理（Reasoning）與反駁（Rebuttal）。
- **實時數據記錄**：點擊「記錄數據」按鈕，實時將當前參數寫入觀測表記錄。

### 📝 課堂探究單工作紙設計標準（每課一張 A4 紙，共 2 版）

- **正面（第 1 版）**：
  - 學校抬頭、週次、單元、PISA 素養領域坐標、學生個人資訊欄。
  - **一、 PISA 2029 素養情境導引與文本審查**：審查生活文本、商品標籤、工程招標、新聞數據，標註基準量與核心變數。
  - **二、 課堂動態實驗操作指引**：實驗原理公式、操作三部曲、觀測數據記錄表（4-6欄位）、規律發現總結填空。
- **背面（第 2 版）**：
  - **三、 CER 學術論證實踐**：主張（結論立場）、證據（數據算理）、推理（底層模型）、反駁（直擊直覺迷思）專用書寫框。
  - **四、 PISA 2029 基礎精準練**：2 道情境計算題，鞏固底層算理與單位率。
  - **五、 PISA 2029 拓展突破題**：1 道高階題目，考核計算思維（CPS 演算法步驟設計）或媒體數據審查（MAIL）。
  - **六、 課堂學習反思與同儕互評**：3 顆星三維評量表。
